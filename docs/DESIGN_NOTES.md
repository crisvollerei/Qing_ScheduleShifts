# 银昼 / 蓝夜设计说明

清蒸排班采用插画手札风格。两套主题共享排班功能与阅读顺序，人物、纹样和配色提供氛围，日期、班次与操作始终是主内容。

## 主题语言

| 部位 | 银昼 · 银翼手札 | 蓝夜 · 深蓝夜航 |
| --- | --- | --- |
| 配色 | 珍珠白、灰紫、冰蓝 | 深海蓝、雾蓝、暖金 |
| 人物衬景 | 不对称冰晶、交错椭圆星轨、流线 | 弦月、星图、轨道、海浪与尾鳍 |
| 页面纹样 | 淡鳞片、银翼轮廓 | 淡金枝叶刺绣、水波 |
| 卡片边饰 | 珠链、银结、菱形吊坠 | 蕾丝、透明底蝴蝶结、尾鳍 |
| 陪伴角色 | 银白大肥龙，可靠、略嘴硬 | 蓝色大肥鱼，贪吃、爱摸鱼 |

主题通过 CSS 变量覆盖背景、文字、卡片、按钮、进度饰扣、日期标记和输入页。标题与月份采用本地楷体 / 衬线字体，功能文字强调可读性，不依赖远程字体。

## 页面结构

- 顶部为完整手札封面：左侧标题，右侧立绘、场景与题签；排班方案和编辑操作在封面下方的实色工具栏中。
- 今日概览集中呈现班次、周期进度、下次休息与倒计时；手机转换为适合窄屏的分组布局。
- 桌面以月历为主区，陪伴、统计与近期安排位于右栏。月历和右栏齐底，年度总览跨栏置于其后。
- 641–960 px 时，陪伴与月历各占一行，统计和近期安排并排；统计使用纵向数据条，与右侧七天安排或日期详情齐底。
- 640 px 及以下采用单列阅读顺序，月历页眉、图例、边饰和日期格同步收紧。
- 年度总览默认折叠；点击日期时，详情替换未来七天，月历网格保持原位。

## 月度统计与操作细节

月度概览沿用月历的班次色点与淡色底，用班次名称、天数和中性的上月对比形成固定阅读顺序。数值采用衬线数字与独立单位，月份作为轻量题签显示。

计划工时下方使用「工作 / 休息」双段比例条，直接标明双方的天数及百分比；按班次的工作属性归类，不按名称或颜色判断。条段长度使用实际天数，文字百分比取整，全工作或全休息月份隐藏空段。休息段增加细斜纹，文字与纹理共同辅助辨认。

月份前后按钮成组排列，近期安排用箭头标识详情入口；日期选中标记为圆点和轮廓，今天有独立顶部标记。触屏采用短暂按压反馈，不使用悬浮位移；输入页保持静态，并遵守减少动态效果设置。

## 月历信息层级

日期详情使用并排的「前一天 / 后一天」按钮，与月历共享导航边界，跨月后同步月份与统计。连续查看保持按钮焦点；关闭详情回到原日期入口。未来或过去的休息日使用「当天休息」，与实际今天区分。陪伴留言区域支持独立的键盘阅读，不触发全局切月快捷键。

日期数字、班次和农历分布在格子的上、中、下区域。普通日期不预留节日插画占位，节日格以淡彩水印和独立标签表达；同日双节允许完整换行。

月首月末用淡色的相邻月份日期补齐整周，仅作参考，不响应选择。今天使用顶部细色条、加深数字和桌面小「今」签；选中日期另有独立轮廓，两者可以同时识别。

节日插画使用共享配色与细描边，两套主题保持一致，避免将节日颜色与工作 / 休息属性混淆。所有节日提示均不代表法定调休安排。

## 立绘、场景与边饰

顶部立绘单独定位，背景场景覆盖整张封面。场景采用不对称构图，并带左侧和底部透明渐隐，不要求立绘始终处于背景中心。

珠链与蕾丝随卡片宽度延伸，在饰扣前渐淡结束。顶框线为饰扣留出缺口，饰扣本身保持透明底；手机上的饰扣避让「今天」等控件。

装饰不接受指针事件，并对辅助阅读隐藏。主内容使用实色底，纹样集中在边框、角落和背景，不覆盖文字、日期或操作区域。

主要素材：

- `assets/character-day.webp`、`assets/character-night.webp`：透明立绘。
- `assets/chibi-day.webp`、`assets/chibi-night.webp`：Q 版陪伴人物；对应 PNG 保留为原图。
- `assets/silver-atrium.svg`、`assets/tidal-observatory.svg`：主题场景。
- `assets/silver-scales.svg`、`assets/silver-pearl-trim.svg`：银昼纹样。
- `assets/night-lace.svg`、`assets/night-embroidery.svg`：蓝夜纹样。
- `index.html` 中的 SVG 符号：结饰、蝴蝶结、吊坠、尾鳍与节日插画。

## Q 版陪伴

陪伴文案以短句和实际排班信息为主。大肥龙以温和的提醒、肯定和一点嘴硬表达关心；大肥鱼以吃饭、摸鱼和打工人的小迷糊缓和疲惫。两者保留轻微反差，不使用过强的人设表演，也不通过文案暗示会实际操作文件或消耗用户资源。

每位角色有 32 条闲聊，打乱后依次出现，一轮内不重复；点击在闲聊与排班提示之间交替，不自动轮播。提示使用当前排班、实际日期和上下班边界，查看其他月份不改变实时信息。

手机和平板陪伴区最多 420 px 宽，短句在固定阅读区内垂直居中，人物贴近气泡底边。长短文案切换不改变人物、底部操作或下方内容位置；极长班次名称在可聚焦的留言区域内滚动。桌面使用右栏独立空间；仅在宽度至少 2070 px 且高度至少 600 px 时浮在页面右侧空白边缘。

人物点击保留短暂轻弹、星光与文字淡入。收起时隐藏气泡，点击人物可恢复展开并换句；倒计时静默刷新，不反复触发读屏播报。

## 动效与可访问性

- 每套场景有两条主要轨道，五枚菱形、星芒和光点沿真实圆形 / 倾斜椭圆运动，周期为 104–132 秒。
- 轨道与标记共用 SVG 坐标和倾斜变换，CSS motion path 与可见路径使用相同几何；大小菱形另以 32 / 46 秒周期反向自转。
- 今日概览与月历页脚有少量低幅星屑，周期饰扣保留低频微光；立绘与整张背景不持续平移或起伏。
- 持续装饰只在可见区域运行；离屏、页面后台或弹窗开启时暂停，不增加动画定时器。
- 切月、详情和人物点击保留短暂反馈；输入页为纯色、无动效的普通文档流，后台实时刷新暂停。
- 遵守 `prefers-reduced-motion`，减少动态效果时关闭持续动画和移动反馈。不支持路径动画时保留轨道、隐藏移动标记。
- 保留浏览器缩放、清晰焦点、键盘导航与弹窗焦点约束；时间信息和状态不只靠颜色表达。

样式分别集中在 `assets/styles.css`、`assets/themes.css`、`assets/festivals.css`、`assets/companion.css` 与 `assets/motion.css` 中。

## 编辑与数据留存

周期编辑由自由文本、班次快捷追加按钮、移除末项和实时预览组成。预览与月历共享班次颜色和时间定义，以日期、名称、时间组成轻量卡片；桌面四列，窄屏两列。预览展示前 16 天，工作 / 休息汇总计算完整周期。预览随用户输入更新，不使用定时刷新或动画。

页脚「备份与恢复」打开与排班设置一致的静态输入页。以「保存 / 恢复」两步组织，手机优先展示复制文本与粘贴预览，同时提供文件下载与文件选择。文本复制失败时，完整只读内容与全选按钮仍可用，不以剪贴板权限作为使用前提；生成区显示完整字符数并提醒另存、未加密。页面不自动读取剪贴板，解析由预览按钮触发。

文件与文本共用数据版本、严格校验、预览和确认恢复路径；编辑文本立即作废预览，过时的文件读取和复制结果不能覆盖当前界面。预览完成后焦点移到摘要，方便窄屏核对并让输入结束；错误定位到页内提示。导入保留旧方案和导入前排班。备份页不上传数据，不依赖新服务，网站版与离线版共享实现；编码与数据版本独立演进，约定见 `BACKUP_FORMAT.md`。

编辑、详情导航和备份页的样式集中于 `assets/experience.css`，使用共享主题变量与减少动态效果规则。

## 个人外观

页脚独立的「头像与标题」入口避免把外观设置混入排班操作。预览卡片沿用主题色、圆角头像和小标题层次；标题可自定义为任意单行文字，应用到品牌区、页脚和标签页，保留原有中间文案与人物。长标题在页首省略显示并提供完整提示，在预览和页脚自然换行，不挤掉主题与导航按钮。

外观设置使用无动效、无后台刷新的静态输入页，打开不自动聚焦文本框。头像选择、标题输入及分别恢复默认都只修改草稿，保存才生效。图片在本地检查文件签名、大小和像素上限，居中裁剪为 256 × 256 静态图；取消、重选或恢复默认会使先前的图片处理结果失效。图片不上传，也不依赖第三方服务。

标题是可移植的数据，进入文件与文本的统一备份契约，并在导入预览中显示。头像是当前设备的外观，不进入备份且导入不覆盖。外观使用独立版本化本地记录，排班方案与排班恢复默认不包含外观；写入失败保留原记录并明确说明本次会话状态。

## Android 封装说明（本仓库）

网页内核自 v2 起改为 ES module 启动（`assets/main.js` → `assets/app.js` 及若干子模块），
因此**不能再用 `file://` 加载**：`file://` 的 origin 为 `null`，module 请求会按跨源处理而被拦截。

`MainActivity` 改用 `WebViewAssetLoader`，把 `assets/` 映射到同源的
`https://appassets.androidplatform.net/` 虚拟地址，module 即可正常加载；
同时关闭了 `setAllowFileAccess`，不再需要开放本地文件访问。

网页内核不再向 `window` 暴露 `CYCLE` / `SHIFT_DEFS` / `closeSettings()` 等全局符号，
原生侧需要的两项能力改由本仓库自有的 `assets/android-bridge.js` 提供，
它由 `assets/main.js` 在 `createApp()` 之后挂载：

| 能力 | 说明 |
| --- | --- |
| 反向读取 | WebView 本地存储被清空时，从小部件侧取回排班；**本地配置优先**，绝不覆盖用户改动 |
| 关闭弹窗 | 返回键先关闭页面内最上层弹窗，再考虑退出应用 |

`android-bridge.js` 与 `main.js` 的挂载行是本仓库相对上游的**唯一差异**，
上游同步时需要重新套用；其余 `assets/` 文件与上游逐字节一致。

## 桌面小部件排版系统

小部件由 RemoteViews 渲染，沿用银昼 / 蓝夜配色与透明 Q 版人物。布局不是网页，不能依赖 CSS 断点；六份 XML 与 Provider 的尺寸预算需要同时维护。

### 阅读顺序与分组

- 顶部日期是独立信息行；刷新固定右上角，使用统一圆形底与 26dp 点击区。
- 班次名称是第一层级，状态与时段紧贴名称。人物只占主视觉行，不压缩方形 / 竖版的日期、周期或计时面板。
- 周期文字与进度条为一组，后续排班紧随其后；整组撤除时连同多余的弹性间隔一起隐藏。
- 方形与竖版底部使用完整内容宽度的浅色计时面板，标签左对齐、数字右对齐。横向卡片另设计时列，宽版使用上下标签，短宽版使用紧凑的行内标签。
- 组内保持固定节拍，组间使用等权弹性留白；增加高度时拉开信息组，不把同一组的名称、时段与状态拆散。

### 圆角安全区

Android 12+ 的背景半径直接引用系统 `system_app_widget_background_radius`，旧系统使用 28dp。运行时用实际半径（不大于短边的一半）计算安全内缩：

`inset = max(档位基线, ceil(R * (1 - 1 / sqrt(2)) + 1dp))`

基线为 mini / mini_wide 10dp、small / companion 12dp、wide / full 14dp。额外安全区施加在根容器，因此文字和覆盖在右上角的刷新按钮同步内缩；重新应用时显式恢复 padding，避免尺寸或宿主圆角变化后留下旧值。

人物与刷新控件不重叠。短宽版为按钮保留一整行；紧凑版人物底对齐，并为刷新保留顶部空间。人物允许在极端圆角的最小尺寸中缩小，优先保证内容安全与可读性。

### 尺寸档位

| 档位 | 布局 | 典型尺寸（dp） |
| --- | --- | --- |
| mini | `widget_layout_mini` | 110×110、110×320、216×110、240×215 |
| mini_wide | `widget_layout_mini_wide` | 360×110、360×144、500×215 |
| small | `widget_layout_small` | 156×216、180×320、215×216 |
| companion | `widget_layout_companion` | 216×216、240×240、320×216 |
| wide | `widget_layout_wide` | 360×216、360×300、500×320 |
| full | `widget_layout` | 224×320、320×320、300×520 |

档位内仍按实际宽高调整字阶：窄高卡强化班次，较宽方卡提升主标题，高于 420dp 的完整卡片使用更大的标题与计时数字。宽度计算分别对应主视觉列、日期行、周期行与计时列，不能用同一个卡片宽度代替所有文字的可用宽度。

### 字体与溢出

字号沿用 `dimens.xml` 和 Provider 的字阶。运行时以 dp 应用设计字号，明确保持固定高度布局的比例，不再使用 `sp / fontScale`（Android 14 的非线性字体缩放下该写法不可靠）。颜色继续通过资源引用跟随宿主深浅色。

日期、时段与周期先选择较短文案，再适配实际列宽。班次名称、时段、倒计时副标题与后续排班的适配使用本次绑定的实际字符串，而不是固定的三个汉字或示例日期。原生 TextClock / Chronometer 保留秒级更新，倒计时至少按 `HH:mm:ss` 预留宽度，并支持五位小时。

### 可见性与验收

`contentHeight()` 按 XML 的真实分组估算高度，包括组内间距、面板 padding、人物最低占位以及横向卡片的头部。空间不足时依次撤除未来七天、倒计时副标题、后续排班、状态、周期与班次时段；日期、班次、时钟、倒计时始终保留。

验收包括六档边界、明暗主题、手机密度、1.0 / 1.3 / 2.0 字号配置、28 / 36 / 48dp 圆角、长班次、3660 天周期及同一视图反复更新。自动测试检查圆角安全、文字完整性、刷新点击与人物不重叠；原生渲染截图生成至 `.qa/widget-previews/`，供逐档视觉复核。桌面厂商的额外外边距与自定义裁切仍需真机检查。
