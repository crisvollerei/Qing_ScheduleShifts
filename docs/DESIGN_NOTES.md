# 银昼 / 蓝夜视觉设计

「清蒸排班」的两套主题：**银昼**（浅色）与**蓝夜**（深色）。
主题覆盖背景、字体、卡片、按钮、进度饰扣、日期徽章与弹窗，
顶部场景与排班工具栏分层排布，窄屏自动缩小人物和装饰。
所有装饰图形使用本地 SVG 绘制，Q 版人物为本地 PNG，不引入外部依赖。

## 布局

- 顶部为一整幅插画手札封面：左侧保留标题与说明，右侧以人物、独立绘制的 SVG 场景和主题题签组成画面。桌面场景约 215–235 像素高；手机约 185 像素高。
- 当前方案、保存方案和编辑排班集中在封面下方的独立工具栏，始终有实色背景。
- 今日班次、周期进度、下次工作和上下班倒计时放入一条横向信息栏。手机上转换为两列，减少顶部纵向堆叠。
- 月历是主区域，桌面宽度约占主体的四分之三；统计与近期安排在右侧。窄屏按阅读顺序转为单列。
- 月度计数、计划工时和工作日占比合为一个统计面板。
- 未来七天与日期详情共享侧栏位置；点击日期时保持月历网格不重建。
- 年度总览默认折叠，需要时展开。仍可点击月份或其中的日期跳转。

## 人物与主题

- 银昼「银翼手札」：珍珠白、灰紫与冰蓝，搭配银翼、双层拱廊、银饰圆环和切面冰晶，对应银白人物。
- 蓝夜「深蓝夜航」：深海蓝、雾蓝与黄铜，搭配弦月、星图、轨道、波浪和尾鳍，对应深蓝人物。
- 原有立绘保留在顶部独立的装饰区，新增的 Q 版互动人物另见「Q 版小陪伴」；两者均不覆盖日历、信息栏、统计、按钮或输入区域。插画不接受鼠标事件，装饰图对屏幕阅读器隐藏。
- 默认跟随设备本地时间：07:00–19:00 为银昼，其余时间为蓝夜。手动主题偏好优先保留；时钟按钮可重新启用自动模式。
- 两张插画在切换主题时柔和交替。使用透明 WebP，合计约 245 KiB；保留透明通道和不透明的白色服饰，避免深色主题出现白底矩形。

## 从服饰延伸的界面元素

两套主题分别绘制了原生 SVG 纹样与饰扣，应用在背景边缘、卡片边框、分隔线、进度条和日期徽章中。

| 部位 | 银昼 | 蓝夜 |
| --- | --- | --- |
| 顶部人物衬景 | 银翼、双层拱廊、银饰圆环、切面冰晶 | 弦月、星图、轨道、海浪和尾鳍 |
| 页面边缘 | 淡鳞片纹、局部银翼轮廓 | 淡金色枝叶刺绣和页脚水波 |
| 月历与侧栏卡片 | 局部珠链、银结、菱形吊坠、压印式角饰 | 连续蕾丝滚边、蝴蝶结、黄铜缝线、尾鳍角饰 |
| 今日概览 | 银紫织带、局部鳞纹 | 雾蓝缎面、黄铜织带与局部刺绣 |
| 周期进度 | 银结饰扣 | 尾鳍形饰扣 |
| 今日与选中日期 | 银紫胸针式圆章、菱形标记 | 带黄铜边的缎面方章、金色纽扣标记 |
| 操作按钮 | 银紫描边与不对称圆角 | 黄铜描边与深蓝缎面 |

装饰层不接受指针事件，独立图形对屏幕阅读器隐藏。主内容使用实色底，纹样集中在边框和空白区域；
小屏会缩小边饰，保留日期、班次及按钮的空间。主题样式集中在 `assets/themes.css`，
纹样文件为 `silver-scales.svg`、`silver-pearl-trim.svg`、`night-lace.svg` 与 `night-embroidery.svg`；
结饰、蝴蝶结、翼形和尾鳍符号以内联 SVG 保存，直接打开 HTML 时也能使用。

`silver-atrium.svg` 和 `tidal-observatory.svg` 为手工绘制的本地矢量场景。
标题和月份采用本地楷体 / 衬线字体，功能文字保持原有字体。
切换主题会同步改变场景、饰环、浮动粒子、纹样、材质与日期选择状态。

## Q 版小陪伴

2026-10-17 新增独立 Q 版小角落，保留既有顶部立绘及手札风格。银昼的大肥龙对应用户提供的 `gpt娘.png`，蓝夜的大肥鱼对应 `大肥鱼.png`，原样复制为 `assets/chibi-day.png`（1052 × 1052）和 `assets/chibi-night.png`（610 × 610），没有重绘、抠图或改色，复制前后 SHA-256 一致。两张 PNG 合计约 1.41 MiB，保留透明通道，默认显示约 82–106 px。

气泡使用对应主题的纸面、细边线和不对称圆角，银昼文字为灰紫 `#76608f`，蓝夜为雾蓝 `#b7cef7`；时间独立加粗并使用青蓝 `#267184` / 暖金 `#f4d39b`。人物平时静止，不增加持续摆动。每次点击轻弹约 440 ms，星光约 520 ms，文案短暂淡入，快速连点取消前一次同元素动画。减少动态效果时关闭脚本动画和移动反馈。

常规桌面使用月历右侧独立网格，手机与平板使用月历上方单独一行；只有 2070 px 以上且高度至少 600 px 的屏幕才在空白右边缘固定悬浮。独立空间避免人物和气泡挡住日期或设置按钮。气泡支持收起，折叠期间仍保持实时信息，点击人物可再次展开。组件位于主内容内部，打开设置或年月选择弹窗时随主内容一起进入 `inert` 状态。

每位角色有六条短句，打乱成不重复的一轮；点击在短句和排班提示间交替。提示一次只显示距离下班 / 距离下次上班、明日班次、下次休息其中一条，复用当前排班与跨日计算。时间显示到分钟，不足一分钟使用「不到1分钟」。倒计时与已有时钟共用更新，不增加计时器；文案没有变化时不重建节点。没有工作班时明确说明，不编造时间；休息日仍有昨日跨日班时，先提示该班结束后休息。明日班次使用文本节点，避免自定义名称被解释为 HTML。

支持键盘 Enter / Space。气泡供辅助技术读取，但仅在用户主动点击时通过独立 `role="status"` 播报，避免实时倒计时持续打断阅读。不保存新配置、不联网生成文案，也不改变已有排班算法或数据格式。样式集中在 `assets/companion.css`，行为集成于 `assets/app.js`。

## 字号与节日卡片

正文基础字号 16 px，工具栏、设置输入、说明与统计等小字通常比正文小 2 px。
日期数字在桌面使用 26 px、手机使用 22 px；班次文字分别使用 14 px、12 px。
节日名称使用独立的彩色标签，桌面 13 px、手机 11 px，窄屏允许完整名称换行。

日期格随内容扩展，桌面每行至少 132 px；手机每行至少 134 px，将日期、班次、农历、插画和节日标签分成独立的五行。
双节同日保留两幅插画和完整名称。节日边色和浅色晕染与班次底色搭配，今日和选中状态仍保留明确的日期章与描边。

十种节日各有一幅手绘 SVG 小插画，存放在 `index.html` 的 symbol 定义中；不增加网络请求。
两套主题使用相同的珊瑚红、玉绿、暖金和雾蓝节日配色，细线与柔和色块延续原有插画风格。

| 节日 | 图案 |
| --- | --- |
| 元旦 | 礼花与星点 |
| 除夕 | 饺子与团圆餐盘 |
| 春节 | 灯笼与梅花 |
| 元宵节 | 花灯与汤圆 |
| 清明 | 柳枝与风筝 |
| 劳动节 | 齿轮与麦穗 |
| 端午节 | 粽子与粽叶 |
| 中秋节 | 圆月、月兔与月饼 |
| 国庆节 | 旗帜与金色枝叶 |
| 重阳节 | 菊花与远山 |

今日概览在节日当天增加横向提示，日期详情也展示同一插画与节日名称；
跨日夜班仍按原起始日计算班次，而节日提示按当前实际日期切换。
节日图案不参与动画，不遮挡操作，不影响班次设置和历法数据。

未来七天列表中的节日行保留第一行的日期、星期和班次，在第二行添加节日名称与小插画，配合淡色背景及描边。
双节同日保留两幅图案及完整名称；今天的侧边标记继续保留。
使用与月历一致的节日判断，支持跨月、跨年及午夜更新，点击节日行继续打开日期详情。

## 动效

- 内容分组进入：约 600 ms，轻微上移，分组错开出现。
- 切换月份：约 260 ms，方向随前进、后退变化。
- 日期详情与七天列表：约 330 ms，短距离淡入。
- 年月选择器弹窗：约 280 ms，轻微缩放及淡入。**输入类弹窗不做入场动画**（见下文）。
- 人物、饰环、冰晶、气泡、星点与水波均为**静态图案**，不再持续运动；
  装饰动画已整体移除，以减少手机端的合成负担。
- Q 版人物点击时保留轻弹与星光短反馈。
- 遵守 `prefers-reduced-motion`。开启减少动态效果后，JavaScript 过渡与脚本动画都不运行。

## 验证

网页内核回归测试共 74 项：核心算法、月份与周期计算、节日与农历、未来七天、
主题切换，Q 版陪伴的人物切换、文案轮换、开工 / 下班 / 跨午夜边界、纯休息周期、
折叠和减少动态效果，以及方案命名表单与输入页隔离。Android 侧另有排班与小部件单元测试。

Q 版组件不写配置、不联网生成文案，也不改变排班算法或已有数据格式；
样式集中在 `assets/companion.css`，行为集成于 `assets/app.js`。

## 保存方案改用页面内表单

原有「保存方案」依赖 `window.prompt()` 取名称。宿主应用未实现原生 JavaScript
输入弹窗时可能返回 `null`、抛错或根本不存在，导致按钮没有任何反馈。
现改为页面内的命名表单，复用既有模态窗口与明暗主题，不增加依赖、不改变存储格式。

命名窗口支持按钮保存与 Enter 提交，中文输入法组字时的 Enter 不提前保存；
空白、超过 40 字符及重名均保留窗口并显示错误。取消、关闭、Esc、点击遮罩都不修改方案。
成功后焦点回到触发按钮，保存期间隔离背景操作，重复提交不新增副本。
沿用既有的本地存储失败提示：存储被禁用或写入失败时只保留会话内方案，并明确说明无法持久保存。

## 输入弹窗与手机键盘

真机反馈命名窗口可以打开，但输入法上滑动画期间会高频闪烁、掉帧。
根因未取得设备渲染跟踪，因此不做单点归因，而是逐轮削减输入期间的绘制负担。

- 保存方案与排班设置的输入弹窗不再做缩放 / 透明度入场动画，也不再使用背景模糊；
  非输入类的年月选择器保留原入场效果。
- 输入弹窗改为普通文档流中的独立输入页：纯色背景，隐藏其余页面与装饰，
  不保留透明遮罩、固定定位、窗口阴影或动态视口高度约束。短屏可达性交给浏览器自身滚动，
  脚本不再读取可见视口、监听 resize/scroll 或强制滚动表单。
- 打开时只聚焦表单容器，不自动唤起输入法；用户主动点击输入框后再输入，
  避免页面切换的首次绘制与键盘上滑同时发生。所有可编辑控件保持至少 16 px 字号。
- 打开时取消正在播放的脚本动画、停止每秒计时器并暂停实时页面改写，
  关闭后立即校正时间、日期与排班，再恢复唯一的每秒计时器。跨午夜打开的草稿不会被后台重绘打断。
- 关闭后恢复原日历滚动位置与触发控件焦点；重复开关不会产生重复计时器。

## 资源版本参数

首页给 `app.js`、`styles.css`、`themes.css` 带上了 `?v=` 查询参数
（当前值 `static-input-20261017`），避免浏览器继续复用旧缓存。

本项目通过 `file:///android_asset/` 加载，查询参数不影响本地读取；
但同步上游时应原样保留上游的参数值，不要手工删掉。
