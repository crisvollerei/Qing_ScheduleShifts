# 测试

## 网页内核

覆盖配置校验与恢复、草稿取消、输入校验、跨日与跨午夜、方案切换与命名表单、
滑动切月、日期边界、节日与农历、主题切换、Q 版陪伴的文案与折叠、备份导入导出、
个性化外观、输入页的绘制隔离，以及网页与原生侧的数据同步。

```sh
npm ci        # 仅首次，安装 jsdom
npm test
```

测试直接读取 `app/src/main/assets/`，与 Android 打包的是同一份文件。

## Android 侧

使用 JUnit 与 Robolectric 测试排班计算、三种小部件构图、旧实例兼容、原生计时和设置同步：

```sh
.\gradlew.bat testOriginalDebugUnitTest testScheduleDebugUnitTest
```

布局测试使用原生 Skia 字体度量与框架宿主，覆盖圆角安全区、不同像素密度与字体大小、
长班名与长小时数、额外内边距、主题重载、旧布局升级和计时器恢复。厂商桌面的字体替换、
休眠策略与交互行为仍可能与测试环境不同。

> Robolectric 的字体行盒明显高于真机（实测约为字号的 2.8 倍，真机约 1.2 倍），
> 因此纵向越界的断言带容差；横向不放宽，左右溢出一定是真的算错了。

## 两端契约测试

网页与原生测试共同读取 `app/src/test/resources/widget-schedule-contract.json`，
校验配置归一化、六种班次风格、自定义班次、跨日边界、长周期和夏令时场景，
避免两端规则各自演进后产生偏差。

## 上班提醒

网页测试覆盖 Android 专有入口、静态输入页与返回、开关及提前量保存、权限状态、
日历预览与确认、草稿和范围变化作废预览、系统时钟日期警告、异步错误与过时回调。

原生测试覆盖无小组件时独立安排、精确权限和通知授权、旧安排失效、去重、跨日与夏令时、
重启恢复、测试闹钟、关闭后的取消边界、前台响铃通知与停止操作、日历批量写入、
重复生成、同日时间更新、归属标记保护、清理范围，以及真实网页桥的异步回传。

响铃页退出测试覆盖独立任务与主页面隔离、停止按钮、通知及超时关闭、过期页面恢复、
返回键、重复关闭、亮屏与锁屏标志清理，以及意外共用任务时不移除主页面。

这些检查不代替手机实测。首次使用应核对权限和音量，并测试锁屏、退出页面、
后台回收、重启首次解锁及省电模式；系统时钟和日历需在手机对应应用里检查实际结果。
